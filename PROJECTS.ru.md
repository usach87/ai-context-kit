# Реестр проектов

Этот файл служит только для навигации. Подробный контекст хранится в папке каждого проекта.

| ID проекта | Название | Описание | Директория |
| --- | --- | --- | --- |
| example-project | Пример проекта | [Краткое описание] | projects/example-project/ |

Используйте уникальный постоянный ID проекта (например, `family-app`). Для нового проекта создайте папку, скопируйте в неё PROJECT.md, CONTEXT.md и INSTRUCTIONS.md, затем добавьте строку в таблицу. Не храните здесь секреты.
