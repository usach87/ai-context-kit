# ChatGPT + GitHub: проверка подключения

🌐 **Язык:** Русский · [English](chatgpt.md)

[← README на русском](../../README.ru.md) · [Быстрый старт](../../QUICKSTART.ru.md)

Используйте доступную интеграцию или коннектор GitHub в ChatGPT. Отдельный официальный GitHub MCP-сервер **не требуется** для этого сценария. Возможность чтения и записи зависит от среды, тарифа и выданных разрешений. Встроенная интеграция GitHub не обязательно равнозначна отдельно настроенному MCP-серверу.

## Перед началом

1. Создайте собственный репозиторий GitHub с тремя заполненными файлами: `PROJECT.md`, `CONTEXT.md` и `INSTRUCTIONS.md`.
2. Подключите GitHub к ChatGPT с необходимыми правами.
3. Проверьте, что в текущем режиме ChatGPT действительно доступны инструменты чтения файлов. Возможность записи проверяйте отдельно.

## Проверка 1 — Чтение

Попросите ChatGPT:

> Прочитай PROJECT.md, CONTEXT.md и INSTRUCTIONS.md из репозитория OWNER/REPO. Кратко перескажи цели, текущее состояние и следующий шаг. Укажи, какие файлы удалось прочитать. Если доступа нет, прямо сообщи об этом.

Замените `OWNER/REPO` на адрес своего репозитория. Убедитесь, что помощник **действительно получил содержимое файлов**, а не предположил, что в них написано.

## Проверка 2 — Запись

Попросите:

> Предложи одно небольшое безопасное изменение в CONTEXT.md. Покажи точные изменения и дождись моего подтверждения перед записью.

После подтверждения попросите сохранить изменение, если ChatGPT поддерживает запись в GitHub. Затем откройте репозиторий и убедитесь, что изменение появилось.

## Проверка 3 — Передача контекста другому AI

Откройте другой AI-клиент, который может читать ваш репозиторий, и попросите получить актуальные три файла. Проверьте, что он видит последние сохранённые изменения.

## Если что-то не работает

- Подключённый аккаунт GitHub **не гарантирует** возможность чтения или записи во всех режимах ChatGPT. Проверяйте доступные действия на практике.
- Если запись недоступна, попросите AI подготовить обновлённый текст и внесите его в GitHub вручную.
- Если чтение через интеграцию недоступно, приложите Markdown-файлы к чату вручную. Для публичного репозитория также можно попробовать прямые ссылки на файлы, если AI умеет открывать их.
- Не храните конфиденциальные данные в публичном репозитории.
