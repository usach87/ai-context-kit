# Claude + GitHub

🌐 **Язык:** Русский · [English](claude.md)

[← README](../README.ru.md) · [Быстрый старт](../QUICKSTART.ru.md)

Используйте встроенную интеграцию GitHub или коннектор, если он доступен в вашей версии Claude. Отдельный GitHub MCP-сервер **не обязателен**, если существующая интеграция предоставляет нужный доступ. Выдавайте только необходимые разрешения и проверяйте чтение и запись отдельно.

## Подключение и проверка

1. Подготовьте собственный репозиторий с заполненными `PROJECT.md`, `CONTEXT.md` и `INSTRUCTIONS.md`.
2. Подключите доступную интеграцию GitHub, если она поддерживается.
3. Попросите Claude прочитать файлы и пересказать текущее состояние проекта. Убедитесь, что он действительно получил их содержимое.
4. После значимого этапа попросите предложить изменения в `CONTEXT.md` и подтвердите их перед сохранением.

## Пример запроса

> Прочитай PROJECT.md, CONTEXT.md и INSTRUCTIONS.md из GitHub-репозитория OWNER/REPO. Расскажи, что уже сделано и какой следующий шаг. Соблюдай инструкции проекта. Если файлы недоступны, сообщи об этом.

Если прямого доступа к GitHub нет, загрузите Markdown-файлы вручную. Для актуальных возможностей подключения ориентируйтесь на документацию Claude.
