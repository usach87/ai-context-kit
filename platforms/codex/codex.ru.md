# Codex

## Как подключить репозиторий

Официальные инструкции OpenAI: [Начало работы с Codex](https://developers.openai.com/codex/quickstart), [MCP в Codex](https://developers.openai.com/codex/mcp).

**В Codex CLI или IDE** откройте локально клонированный GitHub-репозиторий — Codex сможет читать файлы проекта без отдельной GitHub-интеграции. Для доступа к GitHub API можно настроить MCP. **В облачной среде Codex** подключение репозитория и разрешения настраиваются отдельно. Всегда проверяйте доступные инструменты чтения и записи.

Используйте файлы `PROJECT.md`, `CONTEXT.md` и `INSTRUCTIONS.md` непосредственно в репозитории проекта. В AI Context Kit **не требуется создавать AGENTS.md**: единым источником правил остаётся `INSTRUCTIONS.md`.

## Как использовать

1. Откройте репозиторий в среде Codex с доступом к его файлам.
2. Явно попросите Codex прочитать три файла. Не рассчитывайте, что `INSTRUCTIONS.md` будет автоматически обнаружен как специальный файл инструкций.
3. Работайте над задачей с учётом целей, ограничений и текущего состояния проекта.
4. После важного этапа попросите предложить обновление `CONTEXT.md`. Проверяйте правки до записи и коммита.

## Пример запроса

> Прочитай PROJECT.md, CONTEXT.md и INSTRUCTIONS.md из этого репозитория. Используй их как контекст проекта. Назови следующий шаг. Не меняй файлы контекста без моего подтверждения.

Возможности доступа к GitHub, MCP и записи зависят от конкретной среды Codex. Проверяйте их отдельно.
