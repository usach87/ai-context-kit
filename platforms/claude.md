# Claude

🌐 **Language:** English · [Русский](claude.ru.md)

[← README](../README.md) · [Quick start](../QUICKSTART.md)

Use a built-in GitHub integration or connector if your Claude environment supports one. A separate GitHub MCP server is **optional**, not required when a suitable integration already provides repository access. Grant only the permissions needed for your project, and verify reading and writing separately.

Ask Claude to explicitly read PROJECT.md, INSTRUCTIONS.md, and CONTEXT.md from your repository. Before saving updates, review the proposed changes. If direct GitHub access is unavailable, upload or paste the Markdown files manually. Check current Claude documentation for setup and capability details.
