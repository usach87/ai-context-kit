# Cursor

## Как подключить репозиторий

Официальные инструкции Cursor: [Начало работы](https://cursor.com/docs/get-started/quickstart), [MCP и интеграции](https://cursor.com/docs/mcp), [GitHub для веб-агента](https://cursor.com/docs/integrations/github).

**В Cursor IDE** обычно достаточно клонировать репозиторий GitHub и открыть его как локальный проект — отдельный коннектор для чтения этих файлов не нужен. Для внешних действий с GitHub можно подключить GitHub MCP через настройки MCP. **Для Cursor Web Agent** GitHub подключается отдельно. Проверьте права доступа перед записью.

Храните `PROJECT.md`, `CONTEXT.md` и `INSTRUCTIONS.md` в репозитории проекта. Cursor может работать с локальными файлами открытого рабочего пространства; при необходимости настройте поддерживаемый доступ к GitHub или MCP.

## Как использовать

1. Откройте репозиторий проекта в Cursor.
2. Попросите AI явно прочитать три файла контекста. Не предполагайте, что все Markdown-файлы загружаются автоматически.
3. Поставьте задачу с учётом текущего состояния и ограничений проекта.
4. Перед сохранением или коммитом проверьте предложенные изменения контекста.

## Пример запроса

> Прочитай PROJECT.md, CONTEXT.md и INSTRUCTIONS.md из текущего проекта. Кратко перескажи цели и актуальные задачи. Соблюдай INSTRUCTIONS.md. Перед изменением файлов контекста покажи план правок и дождись подтверждения.

Если репозиторий не открыт локально, сначала обеспечьте доступ к файлам или передайте их вручную.
