# Быстрый старт

🌐 **Язык:** Русский · [English](QUICKSTART.md)

[← Описание AI Context Kit](README.ru.md)

AI Context Kit позволяет продолжить работу над **любым проектом** в другом AI-чате без повторного объяснения всего контекста.

## 1. Создайте репозиторий проекта

Скопируйте три файла из папки [template/](template/) в собственный репозиторий GitHub. Для личных или конфиденциальных проектов используйте закрытый репозиторий. Также можно скачать файлы и передавать их AI вручную.

## 2. Опишите проект

Попросите AI:

> Помоги заполнить PROJECT.md, CONTEXT.md и INSTRUCTIONS.md для моего проекта. Задавай только необходимые вопросы. Не придумывай факты и покажи результат перед сохранением.

- **[PROJECT.md](template/PROJECT.md)** — что это за проект и что будет считаться успехом.
- **[CONTEXT.md](template/CONTEXT.md)** — текущее состояние, решения, результаты и следующие шаги.
- **[INSTRUCTIONS.md](template/INSTRUCTIONS.md)** — как AI должен использовать и обновлять контекст.

## 3. Подключите AI-чат к GitHub

Используйте встроенную GitHub-интеграцию или коннектор, если платформа это позволяет. Отдельный GitHub MCP **не обязателен**. Проверьте, что помощник может прочитать ваш репозиторий. Поддержка записи и необходимые разрешения могут отличаться.

**Публичный репозиторий:** некоторые AI-клиенты могут прочитать файлы по открытым ссылкам даже без подключения аккаунта. Проверяйте фактическое чтение файлов, а не обещания помощника.

**Закрытый репозиторий:** нужен авторизованный доступ с подходящими правами.

Если прямой доступ к GitHub недоступен, загрузите Markdown-файлы в чат вручную.

Инструкции для отдельных платформ: [ChatGPT](platforms/chatgpt/chatgpt.ru.md), [Claude](platforms/claude/claude.ru.md), [Cursor](platforms/cursor/cursor.ru.md), [Codex](platforms/codex/codex.ru.md). Папку `platforms/` копировать или заполнять не нужно — это справочные инструкции.

## 4. Работайте и сохраняйте результат

Перед началом попросите AI прочитать актуальные три файла. После значимого этапа попросите предложить обновления `CONTEXT.md`, включая важные решения и следующий шаг. Сначала проверьте и подтвердите изменения, затем сохраните их в GitHub (или вручную, если запись недоступна).

## 5. Перейдите в другой AI-чат

В новом ChatGPT, Claude или другом AI-чате отправьте короткий запрос:

> Прочитай PROJECT.md, CONTEXT.md и INSTRUCTIONS.md из моего GitHub-репозитория OWNER/REPO. Используй их как контекст проекта. Кратко расскажи, что уже решено и какой следующий шаг. Если файлы недоступны, прямо скажи об этом — ничего не выдумывай.

Замените `OWNER/REPO` адресом своего репозитория, например `username/my-project`. Если доступа к GitHub нет, приложите три файла к сообщению.

AI должен **заново читать актуальный контекст**: история сообщений между платформами автоматически не передаётся.

## Дополнительные файлы

Когда контекст станет слишком большим, можно добавить файлы из [optional/](optional/): `DECISIONS.md`, `TASKS.md`, `SOURCES.md`. Для MVP они не обязательны.

## Безопасность

Не сохраняйте в GitHub пароли, токены и другие секреты. Для чувствительных данных используйте закрытый репозиторий и минимально необходимые разрешения интеграций.
