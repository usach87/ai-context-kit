# Быстрый старт

## 1. Создайте общий репозиторий

Создайте, например, `username/my-ai-context` на GitHub. Скопируйте [PROJECTS.ru.md](PROJECTS.ru.md) в корень и переименуйте в `PROJECTS.md`. Скопируйте папку [projects/example-project/](projects/example-project/) целиком в `projects/` своего репозитория.

```text
my-ai-context/
├── PROJECTS.md
└── projects/
    ├── Sophia/
    │   ├── PROJECT.md
    │   ├── CONTEXT.md
    │   └── INSTRUCTIONS.md
    └── I-Design-Award/
        ├── PROJECT.md
        ├── CONTEXT.md
        └── INSTRUCTIONS.md
```

## 2. Переименуйте папку шаблона

Вместо `example-project` укажите понятное уникальное название папки, например `Sophia`. **Отдельный ID проекта не нужен.** Используйте только три файла выбранного языка: английские `PROJECT.md`, `CONTEXT.md`, `INSTRUCTIONS.md` или русские `PROJECT.ru.md`, `CONTEXT.ru.md`, `INSTRUCTIONS.ru.md` (в пользовательском репозитории уберите `.ru` из имён). Лишние языковые версии можно удалить.

Заполните файлы с помощью AI, проверьте результат и добавьте строку в `PROJECTS.md` с названием, описанием и точным путём, например `projects/Sophia/`.

## 3. Подключите GitHub

Настройте доступ в нужном AI-клиенте: [ChatGPT](platforms/chatgpt/chatgpt.ru.md), [Claude](platforms/claude/claude.ru.md), [Cursor](platforms/cursor/cursor.ru.md), [Codex](platforms/codex/codex.ru.md). Подойдёт поддерживаемая интеграция или MCP; можно передать файлы вручную. Проверьте, что AI действительно может прочитать выбранные файлы. Для записи могут потребоваться дополнительные разрешения.

## 4. Привяжите AI-проект к точному пути

Создайте отдельный проект или рабочее пространство в AI-клиенте, если он поддерживает постоянные инструкции. Добавьте туда:

> Репозиторий GitHub: `username/my-ai-context`. Ветка: `main`. Директория активного проекта: `projects/Sophia/`. В начале новой сессии прочитай `projects/Sophia/PROJECT.md`, `projects/Sophia/CONTEXT.md` и `projects/Sophia/INSTRUCTIONS.md` из этого репозитория и ветки. Не читай другие проекты. Если файлы недоступны, укажи точные пути и сообщи об ошибке; не используй чужой контекст. Предлагай обновления только в этой директории и сохраняй после моего подтверждения.

Замените репозиторий, ветку и папку на свои. **Ветка Git (`main`) и папка (`projects/Sophia/`) — разные вещи.** Настройки AI-проекта указывают точные пути, но сами по себе не дают доступа к GitHub и не обеспечивают абсолютной гарантии выполнения. Если постоянных инструкций нет, вставьте этот текст первым сообщением чата.

## 5. Работайте и обновляйте контекст

После значимого этапа попросите AI предложить изменения `projects/Sophia/CONTEXT.md`. Проверьте и подтвердите перед записью. Не перечитывайте другие проекты и не сохраняйте полную переписку.

## 6. Продолжайте работу в другом AI-чате

Откройте AI-проект с тем же настроенным репозиторием и путём. Попросите загрузить свежие файлы и назвать их точные пути. Если настройки не переносятся между платформами, повторите инструкцию из шага 4. Реестр `PROJECTS.md` нужен для обзора проектов, **не для обязательного поиска при каждом старте**.

## 7. Добавляйте проекты

Копируйте `projects/example-project/` для нового проекта, переименовывайте папку, заполняйте три файла и добавляйте строку в `PROJECTS.md`. Для каждого AI-проекта задавайте соответствующий путь. [Дополнительные файлы](optional/) при необходимости размещайте внутри его папки.

**Безопасность:** не сохраняйте секреты. Папки внутри одного репозитория не разделяют права доступа; для разных уровней доступа используйте отдельные репозитории.
