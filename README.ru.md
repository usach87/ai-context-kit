# AI Context Kit

**Передавайте контекст проекта между AI-чатами, не привязываясь к одной платформе.**

🌐 **Язык:** Русский · [English](README.md)

AI Context Kit — открытый набор Markdown-шаблонов для **нескольких проектов в одном GitHub-репозитории**: бизнеса, исследований, творчества, личных задач и разработки. У каждого проекта своя папка с контекстом, который можно использовать в ChatGPT, Claude или другом AI-помощнике.

## Быстрый старт

1. Откройте [пошаговую инструкцию для нескольких проектов](QUICKSTART.ru.md).
2. Создайте общий GitHub-репозиторий и скопируйте в корень [PROJECTS.ru.md](PROJECTS.ru.md), переименовав в `PROJECTS.md`.
3. Для каждого проекта скопируйте папку [projects/example-project/](projects/example-project/), переименуйте её и используйте `projects/project-folder/` и скопируйте в неё три [русских](projects/example-project/PROJECT.ru.md) или [английских](projects/example-project/PROJECT.md) шаблона. Итоговые имена: `PROJECT.md`, `CONTEXT.md`, `INSTRUCTIONS.md`.
4. Добавьте проект в реестр `PROJECTS.md` и настройте доступ AI к GitHub.
5. Укажите путь активного проекта в постоянных инструкциях AI-проекта или в первом сообщении чата. AI должен читать и изменять **только файлы выбранного проекта**.

```text
my-ai-context/
├── PROJECTS.md
└── projects/
    ├── project-one/
    │   ├── PROJECT.md
    │   ├── CONTEXT.md
    │   └── INSTRUCTIONS.md
    └── project-two/
        ├── PROJECT.md
        ├── CONTEXT.md
        └── INSTRUCTIONS.md
```

## Три основных файла

| Файл | Назначение |
| --- | --- |
| [PROJECT.md](projects/example-project/PROJECT.ru.md) ([EN](projects/example-project/PROJECT.md)) | Цели, аудитория, границы и ограничения проекта |
| [CONTEXT.md](projects/example-project/CONTEXT.ru.md) ([EN](projects/example-project/CONTEXT.md)) | Текущее состояние, ключевые решения, последние результаты и следующий шаг |
| [INSTRUCTIONS.md](projects/example-project/INSTRUCTIONS.ru.md) ([EN](projects/example-project/INSTRUCTIONS.md)) | Правила работы AI с общим контекстом |

Три файла хранятся **в каждой папке проекта**, а корневой `PROJECTS.md` нужен только для поиска нужной директории. Если проект усложнится, можно использовать дополнительные файлы из папки [optional/](optional/): журнал решений, задачи и источники. **Для начала они не нужны.**

Инструкции для платформ на русском: [ChatGPT](platforms/chatgpt/chatgpt.ru.md), [Claude](platforms/claude/claude.ru.md), [Cursor](platforms/cursor/cursor.ru.md), [Codex](platforms/codex/codex.ru.md).

## Как это работает

Выбираете активный проект → AI читает три файла из его папки → работаете и сохраняете согласованные обновления → открываете другой AI-чат → AI снова читает файлы **того же проекта**.

**Это не автоматическая синхронизация переписки.** Передаются структурированные знания о проекте; каждый помощник должен получить актуальную версию файлов. Возможность записи зависит от конкретной интеграции и прав доступа.

## Принципы

- **Для любых проектов:** навыки программирования не требуются.
- **Независимость от платформы:** обычные Markdown-файлы.
- **Контроль пользователя:** данные и история изменений находятся в вашем репозитории.
- **MCP необязателен:** встроенной GitHub-интеграции может быть достаточно; можно передавать файлы вручную.
- **Согласование:** важные изменения контекста сохраняются после подтверждения пользователя.
- **Изоляция контекста:** AI не загружает другие проекты без необходимости. Папки GitHub не разделяют права доступа: при разных требованиях к доступу нужны отдельные репозитории.
- **Приватность:** не публикуйте конфиденциальные данные; при необходимости используйте закрытый репозиторий.

## Статус

Минимальный MVP. Собственный сервер, база данных и отдельный MCP-сервер не требуются.
