# AI Context Kit

**Передавайте контекст проекта между AI-чатами, не привязываясь к одной платформе.**

🌐 **Язык:** Русский · [English](README.md)

AI Context Kit — открытый минимальный набор Markdown-шаблонов для **любых проектов**: бизнеса, исследований, творчества, личных задач и разработки. Контекст хранится в вашем собственном GitHub-репозитории, чтобы работу можно было продолжить в ChatGPT, Claude или другом AI-помощнике.

## Быстрый старт

1. Откройте [пошаговую инструкцию на русском](QUICKSTART.ru.md).
2. Скопируйте **три файла** из папки [template/](template/) в собственный репозиторий.
3. Попросите AI помочь заполнить шаблоны.
4. Подключите GitHub через доступную интеграцию, коннектор или MCP (необязательно). Если доступа нет — передайте файлы вручную.
5. В новом AI-чате попросите заново прочитать актуальные файлы. Проверяйте и подтверждайте изменения перед сохранением.

## Три основных файла

| Файл | Назначение |
| --- | --- |
| [PROJECT.md](template/PROJECT.md) | Цели, аудитория, границы и ограничения проекта |
| [CONTEXT.md](template/CONTEXT.md) | Текущее состояние, ключевые решения, последние результаты и следующий шаг |
| [INSTRUCTIONS.md](template/INSTRUCTIONS.md) | Правила работы AI с общим контекстом |

Если проект усложнится, можно использовать дополнительные файлы из папки [optional/](optional/): журнал решений, задачи и источники. **Для начала они не нужны.**

Инструкции для платформ: [ChatGPT](platforms/chatgpt.md), [Claude](platforms/claude.md), [Cursor](platforms/cursor.md), [Codex](platforms/codex.md) (пока на английском).

## Как это работает

Работаете над проектом в одном AI-чате → сохраняете согласованные обновления в общие Markdown-файлы → открываете другой AI-чат → просите прочитать свежие файлы из GitHub.

**Это не автоматическая синхронизация переписки.** Передаются структурированные знания о проекте; каждый помощник должен получить актуальную версию файлов. Возможность записи зависит от конкретной интеграции и прав доступа.

## Принципы

- **Для любых проектов:** навыки программирования не требуются.
- **Независимость от платформы:** обычные Markdown-файлы.
- **Контроль пользователя:** данные и история изменений находятся в вашем репозитории.
- **MCP необязателен:** встроенной GitHub-интеграции может быть достаточно; можно передавать файлы вручную.
- **Согласование:** важные изменения контекста сохраняются после подтверждения пользователя.
- **Приватность:** не публикуйте конфиденциальные данные; при необходимости используйте закрытый репозиторий.

## Статус

Минимальный MVP. Собственный сервер, база данных и отдельный MCP-сервер не требуются.
