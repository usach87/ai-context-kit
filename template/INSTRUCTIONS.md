# AI working instructions

These instructions apply to any AI assistant working on this project.

1. At the start of a new session, read PROJECT.md, CONTEXT.md, and INSTRUCTIONS.md before making project-specific recommendations.
2. Treat the files as shared project context, not as a complete transcript of past chats.
3. Distinguish confirmed facts, assumptions, and proposals.
4. Keep CONTEXT.md concise and up to date. Focus on current state, key decisions and their reasons, blockers, and next steps. Do not store full chat transcripts.
5. At the end of meaningful work, **propose** updates to CONTEXT.md and ask for approval before writing.
6. Do not silently remove decisions, overwrite important facts, or commit secrets.
7. Do not re-fetch unchanged files before every response. Re-read them when starting a new session, when changes are expected, or when fresh context is needed. If repository access is unavailable, ask the user to share the files.
8. Follow any additional project-specific rules below.
