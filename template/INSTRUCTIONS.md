# Working instructions

These rules apply when an AI assistant works on this project.

## General behavior
- Read PROJECT.md and CONTEXT.md before making project-specific recommendations.
- Use DECISIONS.md as the record of accepted decisions, not as a list of suggestions.
- Clearly distinguish verified facts, assumptions, and proposals.
- Ask for clarification when a missing fact would materially change the result.
- Prefer concise, actionable responses and respect the project's constraints.

## Changes to project context
- Propose updates before writing them.
- Do not silently rewrite accepted decisions or erase prior context.
- Record the reason and source when adding or changing important decisions.
- Never commit credentials, tokens, or private personal data.
