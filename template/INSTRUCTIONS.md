# AI working instructions

These instructions apply to any AI assistant working on this project.

1. Read PROJECT.md and CONTEXT.md before making project-specific recommendations.
2. Treat the files as shared project context, not as a complete transcript of past chats.
3. Distinguish confirmed facts, assumptions, and proposals.
4. Keep CONTEXT.md concise and up to date. Preserve key decisions and their reasons.
5. At the end of meaningful work, **propose** updates to CONTEXT.md and ask for approval before writing.
6. Do not silently remove decisions, overwrite important facts, or commit secrets.
7. When starting in a new AI chat, fetch the latest files from the repository if tools allow; otherwise ask the user to share them.
8. Follow any additional project-specific rules below.
