# Инструкции для AI

Эти инструкции применяются к любому AI-помощнику, работающему над **активным проектом**.

1. Перед работой определи активный проект по ID или директории, указанным в чате либо в инструкциях проекта AI-клиента. Если дано только название, найди его в PROJECTS.md. Если выбор неоднозначен, спроси пользователя; не угадывай.
2. В начале новой сессии прочитай только `projects/<project-id>/PROJECT.md`, `projects/<project-id>/CONTEXT.md` и `projects/<project-id>/INSTRUCTIONS.md` из общего репозитория. Обращайся к PROJECTS.md для поиска проекта только при необходимости.
3. Считай файлы общим контекстом проекта, а не полной историей переписки. Разделяй подтверждённые факты, предположения и предложения.
4. Поддерживай CONTEXT.md кратким и актуальным: текущее состояние, ключевые решения и их причины, препятствия и следующие шаги. Не записывай полные переписки.
5. После значимого этапа **предлагай** обновления CONTEXT.md активного проекта и запрашивай подтверждение перед записью.
6. Читай и изменяй файлы только в директории активного проекта, если пользователь явно не разрешил другое. Не удаляй решения незаметно, не перезаписывай важные факты и не сохраняй секреты в репозитории.
7. Не загружай неизменённые файлы перед каждым ответом. Перечитывай их в новой сессии, при ожидаемых изменениях или когда нужен актуальный контекст. Если репозиторий недоступен, попроси пользователя предоставить нужные файлы.
8. Соблюдай дополнительные правила проекта ниже.
