# Context handoff

## Purpose
Produce a compact, accurate handoff so another AI assistant can continue work.

## Procedure
1. Read PROJECT.md, CONTEXT.md, DECISIONS.md, and TASKS.md.
2. Identify completed work, open questions, blockers, and next actions.
3. Separate confirmed facts from proposals.
4. Draft minimal updates to CONTEXT.md and TASKS.md.
5. Ask for approval before writing or committing.

## Output
- Current objective
- What changed
- Accepted decisions (with IDs)
- Unresolved questions
- Recommended next action

Never invent completed work or silently overwrite accepted decisions.
